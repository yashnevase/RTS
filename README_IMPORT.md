# Importing the DECCAN LORDS starter into your repository

This package is a **design + AI workflow starter**, not a runnable Godot game yet. It preserves the earlier Game Bible and adds local-agent context and workflow instructions based on the discussion through 2026-10-16.

1. Create or open your private `deccan-lords` Git repository.
2. Copy these files/folders to its root: `AGENTS.md`, `PROJECT_CONTEXT.md`, `CHATGPT_VSCODE_WORKFLOW.md`, `README_IMPORT.md`, and `DECCAN_LORDS_GAME_BIBLE/`.
3. Commit the baseline. Keep the exported v0.1 DOCX/PDF/XLSX in the Bible's `exports/` as historical snapshots; canonical changes belong in Markdown.
4. Open the repo root in VS Code and use Codex with `AGENTS.md`.
5. The real game code can be added after the engine/prototype decision and first vertical-slice specification are settled.

Do not treat anything labelled PROPOSED/OPEN as a locked requirement.
