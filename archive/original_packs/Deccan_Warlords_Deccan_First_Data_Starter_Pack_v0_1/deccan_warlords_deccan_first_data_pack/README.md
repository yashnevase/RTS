# Deccan Warlords — Deccan-first data starter pack

This pack accompanies `Deccan_Warlords_Deccan_First_World_Data_Design_v0_1.md`.

The JSON files are examples and starter contracts. They are not a populated historical database. The example character and house are fictional and must never be mistaken for historical people.

## Structure

- `templates/`: minimal records illustrating the intended relationships between geography, people, families, clans, polity, settlement, skills, troops and scenario data.
- The full design rationale and rule descriptions are in the main Markdown document.

Before implementation, convert the examples into Zod or JSON Schema validators and add automated referential-integrity tests.
